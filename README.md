# 本地量子计算实验台

小规模、纯本地的量子线路实验台：Python 负责真实状态向量计算，React 负责线路编辑与结果展示。不依赖任何量子云服务。

## 启动

```bash
# 终端 1：后端 API（127.0.0.1:8000）
.venv/bin/python -m backend.server

# 终端 2：前端界面（127.0.0.1:5173）
cd frontend
npm run dev
```

打开 Vite 输出的本地地址即可。Vite 已配置 `/api` 代理到 Python 后端。

## 第一轮支持范围

- 量子位规模：1-4 个量子位。
- 初始状态：计算基态，如 `0`、`00`、`0101`。
- 单量子位门：`H`、`X`、`Y`、`Z`、`S`、`T`。
- 旋转门：`RX(theta)`、`RY(theta)`、`RZ(theta)`，角度使用弧度。
- 双量子位门：`CNOT(control, target)`、`CZ(control, target)`、`SWAP(a, b)`。
- 测量：`MEASURE(q)` 在后端执行计算基投影测量并归一化坍缩状态；后续门和测量使用坍缩后的状态。
- 随机种子：随项目线路保存；同一种子与线路可复现逐步测量和重复实验结果。
- 版本保存：线路保存到本地 `data/circuits.json`，同名再次保存会递增版本号。

非法范围（包括量子位越界、双位门两端相同、旋转角不是有限数值、初始基态格式错误等）由后端 `/api/validate` 校验；前端会标红对应步骤并禁止开始运行。

## 逐步执行

前端点击“开始并逐步执行”会在后端创建会话并立即执行第一步；会话状态保存在后端，继续点击“执行下一步”时，测量结果和坍缩后的状态会持续影响后续步骤。右侧实时显示每个计算基的概率和测量记录。

逐步请求进行中时按钮会被禁用，避免重复点击产生竞态；线路执行完毕后再次点击“下一步”不会报错，后端幂等返回最终快照并给出明确提示。固定种子下，逐步执行与 `/api/simulate` 一次运行的测量序列、每一步概率完全一致。

## 中途保存、恢复与分支比较

- 逐步执行过程中可随时点击“保存当前状态”。保存点包含坍缩后的状态向量以及随机数生成器（RNG）的内部状态，存于后端内存。
- “从保存点继续”会创建新会话：之前已发生的测量结果原样保留，不会因为恢复而重新抽取；后续测量从保存时的 RNG 位置继续。
- “保存点后续分支比较”允许在同一保存点上分别编辑两条后续线路（支持关联量子位与测量后的条件操作）。比较时两个分支各自拿到保存状态与 RNG 的独立拷贝，随机序列公平一致，且不修改保存点和当前交互会话。
- “运行独立分支统计”会为每个条件建立独立分支：共同前缀（保存点前的步骤、坍缩状态和测量事实）只保存在批次元数据中，条件步骤、计数、频率、RNG 状态和样本来源按分支分别记录，绝不把不同条件的计数合并。
- 分支批次保存到本地 `data/branch_experiments/<run_id>.json`；到达预算后可停止，之后用运行 ID 单独恢复，并在需要时提高预算追加样本。追加只从每个分支自己保存的 RNG 位置继续。
- 每个分支使用由根种子、保存点 ID 和稳定分支身份派生的独立随机流；改变分支执行顺序或把 JSON 保存文件移动到另一个保存目录，都不会改变同一身份分支的可重放统计。

重复实验统计走独立接口与独立 RNG，不会消耗或串改任何交互会话/保存点的随机数状态。

## 样例与核对

- 单量子位样例：`|0>` 后接 `H`，理论概率为 `P(0)=P(1)=0.5`。
- 关联量子位样例：`H(q0)` + `CNOT(q0,q1)` 产生 Bell 态，理论概率只有 `|00>` 与 `|11>`，各为 0.5；先测量 q0 后，q1 的结果必然与 q0 相同。
- 重复实验可设置 1-100000 次，柱状图同时展示实测频率和后端给出的理论概率。

## 验证

```bash
.venv/bin/python -m pytest backend/tests -q
cd frontend && npm test && npm run build
```

当前自动化核对覆盖：H/RX 概率、Bell 态关联统计、测量坍缩驱动后续 CNOT、同种子重复实验可复现、非法连接校验、后端会话、版本持久化、逐步与一次运行逐步一致（含测量后条件门）、结束后重复点击幂等、保存点恢复不重抽测量、两分支后续比较、统计实验不串入会话 RNG。
当前自动化核对还覆盖：中途测量后多个条件分支共享前缀但计数独立、改变分支执行顺序不改变同身份分支结果、运行到预算上限后持久保存、提高预算后恢复并追加样本、保存文件更换目录后统计结果不变。

## 预留方向

后续可在现有状态向量内核上加入噪声模型、错误率参数、算法实验模板与更多统计分析，不需要改变前端“后端真实计算”的数据流。
